# Snake Game Using Python

## Project Overview
This project is a classic Snake Game developed using Python. The player controls a snake to collect food, grow longer, and achieve a higher score while avoiding collisions.

## Features
- Control the snake using keyboard arrow keys.
- Collect food to increase the score.
- Snake grows after eating food.
- Game-over condition when the snake hits a wall or itself.
- Score tracking during gameplay.

## Technologies Used
- Python 3
- Pygame (if used in this project)

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Install Pygame if your code uses it:

   `pip install pygame`

4. Run the Python file:

   `python snake.py`

5. Use the arrow keys to play.
